SMS Spam Classifier

Technologies: Python, Pandas, NumPy, Scikit-learn, NLTK, Streamlit
•Developed a machine learning model to classify SMS messages as Spam or Ham using Natural Language Processing (NLP).
•Performed text preprocessing, including tokenization, stop-word removal, stemming, and TF-IDF vectorization.
•Trained and evaluated classification models to achieve accurate spam detection.
•Built an interactive web application using Streamlit for real-time SMS classification.
